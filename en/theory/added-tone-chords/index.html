Added-Tone Chords

An added tone expands a regular chord without replacing its foundation. That is why Cadd9 is not a sus chord and not a seventh chord, but C major with an added D.

June 19, 2026
Reader level: Composer

A regular chord can be made wider without turning it into a seventh chord and without removing its third.

For example, a C major chord has three notes:

C = C–E–G

If we add D, we get Cadd9:

Cadd9 = C–E–G–D

The chord is still major: it still contains E, the third. But the sound becomes wider, softer, and richer.

That is how added-tone chords work.

Simple definition

An added-tone chord is a chord where the basic triad remains in place, and one extra note is added to it.

For example:

Cadd9 = C–E–G–D

The regular C major triad is still inside:

C–E–G

And D adds a new color.

The main idea: an add chord does not replace the notes of the triad. It adds another degree to them.

What add means

add means “add”.

In chord symbols, it means: take a regular chord and add the specified degree.

For example:

Cadd9 = C + 9
Cadd2 = C + 2
Cadd4 = C + 4
Cadd6 = C + 6

If we start with C:

C = C–E–G

we get these variants:

Cadd2 = C–D–E–G
Cadd4 = C–E–F–G
Cadd6 = C–E–G–A
Cadd9 = C–E–G–D

All these chords keep the foundation C–E–G. That is why they are still heard as variants of C major, not as completely different chords.

Formulas for added tones

The main formulas look like this:

ChordFormulaNotes from CWhat was added
C1–3–5C–E–Gnothing
Cadd21–2–3–5C–D–E–Gsecond degree
Cadd41–3–4–5C–E–F–Gfourth degree
Cadd61–3–5–6C–E–G–Asixth degree
Cadd91–3–5–9C–E–G–Dninth

The formula is more useful than the fingering. On guitar, the same Cadd9 can be played in different ways, but its meaning stays the same: it is a C chord with an added D.

Why an added tone does not change the foundation of the chord

The foundation of a chord is defined by the main notes of the triad:

1–3–5

For C major, that is:

C–E–G

If these notes remain, the chord keeps its character.

For example:

Cadd9 = C–E–G–D

Here C, E, and G are all present. That means the C major foundation is still there. D does not replace E and does not turn the chord into something suspended. It simply adds color.

That is why Cadd9 sounds like a wider C major chord, not like a sus chord.

Add and sus: what is the difference?

This is the most important point of confusion.

In a sus chord, the third is replaced.

In an add chord, the third remains.

Compare:

Csus2 = C–D–G
Cadd9 = C–E–G–D

Csus2 has no E. The third is gone, so the chord does not sound clearly major or minor.

Cadd9 keeps E. The chord still sounds like C major, but with an added D.

In short:

sus = the third was removed
add = the third stayed, and another degree was added

The same idea applies to sus4 and add4:

Csus4 = C–F–G
Cadd4 = C–E–F–G

Csus4 has no E. Cadd4 keeps E.

Add and seventh chord: what is the difference?

A seventh chord contains a seventh.

For example, Cmaj7:

Cmaj7 = C–E–G–B

C7:

C7 = C–E–G–B♭

An add chord does not have to contain a seventh. Most often, it does not.

For example:

Cadd9 = C–E–G–D

This chord has the ninth, D, but no seventh: no B and no B♭.

This matters: Cadd9 and C9 are not the same chord.

Cadd9 = C–E–G–D
C9    = C–E–G–B♭–D

C9 contains the minor seventh B♭. That is why C9 sounds like a dominant chord. Cadd9 sounds softer and closer to regular C major.

Add2, add9, add4, and add11: what is the difference?

In theory, add2 and add9 point to the same degree, but in a different register sense.

From C:

2 = D close to the root
9 = D an octave higher

The same idea applies to add4 and add11:

4  = F close to the root
11 = F an octave higher

So on paper, you can describe different voicings:

Cadd2 = C–D–E–G
Cadd9 = C–E–G–D

or:

Cadd4  = C–E–F–G
Cadd11 = C–E–G–F

But on guitar, this difference often almost disappears. A chord symbol usually does not define the exact octave of every note. It tells you which notes should be present in the chord.

So in practice, Cadd2 and Cadd9 often mean the same thing: a C chord with an added D.

Cadd2 / Cadd9 = C–E–G + D

The same applies to Cadd4 and Cadd11:

Cadd4 / Cadd11 = C–E–G + F

For a guitarist, the more important question is the actual note content: did the third E remain, and was the added degree included? If E remains, it is an add chord. If E disappears, it is sus.

The difference between add2 and add9, or between add4 and add11, matters only when the arrangement requires a specific voicing. For example, if D must sound close to C, add2 is the more precise label. If D must sound on top as a chord extension, add9 is closer to the intended sound.

In regular guitar notation, add9 is more common because it is the familiar symbol for a soft chord extension. But when you see add2, do not look for a completely different chord right away: check the notes and the actual fingering first.

Cadd9

Cadd9 is one of the most common add chords.

Formula:

1–3–5–9

From C:

Cadd9 = C–E–G–D

Cadd9 sounds wider than a regular C chord, but not as tense as dominant-function seventh chords.

Compare:

C     = C–E–G
Cadd9 = C–E–G–D

D adds air. The chord remains stable, but it becomes less plain.

This sound is common in pop, rock, folk, acoustic parts, and soundtracks.

Cadd2

Cadd2 is built with this formula:

1–2–3–5

From C:

Cadd2 = C–D–E–G

Cadd2 sounds denser than Cadd9 because D sits close to C and E. This can create a nice friction between neighboring notes:

C–D–E

Sometimes that density is exactly what you need. But on guitar, it is not always easy to play cleanly, so players often use a shape that feels closer to Cadd9 instead.

Cadd4

Cadd4 is built with this formula:

1–3–4–5

From C:

Cadd4 = C–E–F–G

Cadd4 sounds tenser than Cadd9. The reason is the closeness of E and F:

E–F

These notes are very close. They create friction.

This chord can sound beautiful, but it is harder to use as a soft background. In song practice, Csus4 is more common, because E is removed:

Csus4 = C–F–G

Cadd4 keeps both E and F:

Cadd4 = C–E–F–G

That is why Cadd4 sounds denser and sharper.

Cadd6

Cadd6 is built with this formula:

1–3–5–6

From C:

Cadd6 = C–E–G–A

In practice, this chord is more often called simply C6:

C6 = C–E–G–A

But conceptually, it also works like an added tone: we add the sixth degree, A, to a regular C major chord.

C6 sounds soft, bright, and slightly jazzy. Unlike Cmaj7, it does not contain the major seventh B, so it often sounds calmer.

Added tones in minor chords

Added tones also work in minor chords.

For example, A minor:

Am = A–C–E

We can add the ninth:

Amadd9 = A–C–E–B

The chord remains minor because it still contains C, the minor third. But B adds air and a light sense of uncertainty.

Another example:

Dmadd9 = D–F–A–E

This sound is often used in acoustic music, ambient music, soundtracks, and melancholic progressions.

How added tones work in progressions

An added tone can make a simple progression more alive without changing the harmony.

For example:

C → G → Am → F

We can replace C with Cadd9:

Cadd9 → G → Am → F

The harmony is almost the same, but the first chord sounds wider.

Another option:

Am → F → C → G

We can use Amadd9:

Amadd9 → F → C → G

The added ninth makes the minor chord less direct and more atmospheric.

Why added tones are comfortable on guitar

On guitar, add chords often appear naturally.

Sometimes you only need to leave an open string ringing, and a regular chord gets an extra degree.

For example, open-position shapes can easily create sounds like:

Cadd9
Gadd9
Dadd9
Amadd9

These chords work well in fingerpicking, strumming, arpeggios, and acoustic parts. They add more air without requiring complex harmony.

The important thing is to understand not only the shape, but also the added degree:

Cadd9 = C + D
Amadd9 = Am + B
Dadd9 = D + E

When you see the added note as an interval, the fingering stops being random.

How to see an added tone on the fretboard

To understand an add chord on the fretboard, find two things:

1–3–5 = chord foundation
added degree = color

For Cadd9:

C = 1
E = 3
G = 5
D = 9

For Cadd4:

C = 1
E = 3
G = 5
F = 4

For Amadd9:

A = 1
C = ♭3
E = 5
B = 9

The main question is: did the third stay or disappear?

If the third stayed, it is an add chord:

Cadd9 = C–E–G–D

If the third disappeared, it is sus:

Csus2 = C–D–G

Listen to what changes:

C      = simple foundation
Cadd9  = foundation + air

The main goal is to hear that add9, sus2, and maj7 create different colors, even though all of them may feel like “beautiful” versions of C.

  2. Find Cadd9.

Do not add new notes to every chord automatically. Sometimes one Cadd9 in the right place works better than add9 on every step.

Common mistakes

Confusing add and sus. In an add chord, the third remains. In a sus chord, the third is replaced by the second or fourth degree.

Confusing Cadd9 and C9. Cadd9 has no seventh. C9 contains the minor seventh B♭.

Thinking that add2 and add9 always sound the same. The note may be the same, but register and voicing change the feeling of the chord.

Playing too many added tones in a row. If every chord is extended, the ear stops noticing the color. An added tone works better when it has contrast.

Memorizing only the fingering. A shape is useful, but it is more important to understand which degree was added: 2, 4, 6, or 9.

Calling every beautiful open chord add9. Check the actual notes first. If there is no third, it may be sus. If there is a seventh, it is already another chord type.

Short summary

Added-tone chords keep the basic triad and add one new note to it. That is why Cadd9 is not a sus chord and not a seventh chord, but C major with an added D. The rule is simple: if the third remains, it is add; if the third is replaced, it is sus; if a seventh appears, it is already a seventh chord or an extended chord. Added tones help make simple harmony wider, softer, and more expressive without fully changing its function.
