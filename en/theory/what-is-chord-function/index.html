What Is Chord Function?

A chord name tells you which notes the chord contains. Chord function explains what role that chord plays inside a key: stability, motion, or tension.

July 21, 2026
Reader level: Arranger

A chord can be described by its name:

C = C–E–G
G = G–B–D
Am = A–C–E

But the name only tells you the chord’s notes. It does not explain why the chord appears in a progression.

For that, you need function.

Chord function is the role a chord plays in harmonic motion inside a key.

Function answers a practical question:

What is this chord doing right now?

It can create stability, move away from stability, prepare tension, or bring the music back to the center.

Function depends on the key

The same chord can have different functions.

For example, the chord G:

G in C major = V, dominant
G in G major = I, tonic
G in D major = IV, subdominant area

The chord has not changed. Its place in the key has changed.

The same applies to C:

C in C major = I
C in G major = IV
C in A minor = III

That is why you cannot identify function from the chord name alone. You need to know the key and hear the context.

Three basic functions

In simple tonal harmony, there are three basic functions.

FunctionWhat it doesSimple feeling
toniccreates the center and stability“we are home”
subdominantmoves away from the tonic and opens motion“we have left home”
dominantcreates tension and pulls back to the tonic“we need to return”

In C major, the basic route looks like this:

I → IV → V → I
C → F  → G → C

You can hear the motion:

stability → departure → tension → return

The first C establishes the center. F moves away from that center. G creates expectation. The final C closes the progression.

Function is not chord quality

Function is easy to confuse with chord quality: major, minor, diminished.

But quality describes interval structure. Function describes the chord’s role in motion.

In C major, the three primary chords are all major:

C = I  = tonic
F = IV = subdominant area
G = V  = dominant

They are all major chords, but their functions are different.

A minor chord is not automatically weak or passing. For example, Dm often prepares the dominant:

Dm → G → C
ii → V → I

So you cannot say, “a major chord is tonic” or “a minor chord means motion.” The chord’s place in the key decides its function.

Tonic function

Tonic function creates the feeling of a center.

In C major, the main tonic chord is:

I = C

Music can begin, pause, or end on this chord.

But the tonic area can also include more than I. In C major, iii and vi sit close to the tonic:

I   = C
iii = Em
vi  = Am

They do not fully replace the tonic, but they can extend the feeling of stability or create a similar kind of support with a different color.

For example, C and Am share two notes:

C  = C–E–G
Am = A–C–E

That is why vi sounds close to the tonic, but softer and darker.

Compare:

C → G → C
I → V → I

and:

C → G → Am
I → V → vi

In the second version, the dominant does not resolve to the tonic. It moves to vi instead. The sense of closure becomes weaker, but the progression gains continuation.

Subdominant and predominant area

The subdominant moves away from the tonic.

In C major, the main subdominant chord is:

IV = F

This motion:

C → F
I → IV

sounds like a step away from the center.

In practical harmony, ii belongs close to this area:

ii = Dm

ii often prepares the dominant:

Dm → G → C
ii → V → I

That is why theory often uses the term predominant function: these are chords that come before the dominant and prepare it.

For a first practical map, this is enough:

IV and ii = motion from tonic toward dominant

This does not mean that IV and ii sound the same. They have a similar role, but a different color.

Dominant function

Dominant function creates tension and has the strongest pull back to the tonic.

In C major, the main dominant chord is:

V = G
G = G–B–D

It contains the leading tone B, which pulls toward the tonic C:

B → C
7 → 1

That is why this motion:

G → C
V → I

sounds like a clear return.

If you add the seventh F to G, you get G7:

G7 = G–B–D–F

It contains two strong resolutions toward the tonic chord:

B → C
F → E

That is why V7–I sounds more directed than a simple V–I.

The leading-tone chord: vii°

The chord built on the seventh degree also belongs to the dominant area.

In C major:

vii° = Bdim
Bdim = B–D–F

It contains the upper notes of G7 without the root:

G7   = G–B–D–F
Bdim =   B–D–F

So vii° can lead to I:

Bdim → C
vii° → I

In song-based harmony, V and V7 are more common. But vii° clearly shows that dominant function is not just about a chord name. It is about tension tones and how they resolve.

Function map in major

For a major key, the basic practical map looks like this:

AreaDegreesRole
tonic areaI, iii, vicenter, stability, closeness to the center
predominant areaii, IVmovement away from the center, preparation of tension
dominant areaV, vii°tension, return to the center

This map helps you orient yourself, but it is not a rigid law.

A chord’s actual function depends on:

  • key;
  • chord order;
  • bass line;
  • inversion;
  • duration;
  • melody;
  • strong beats;
  • listener expectations.

The same chord can feel different in different places within a phrase.

Why chord order matters

Take the same chords:

C, F, G

Arrange them like this:

C → F → G → C
I → IV → V → I

You get clear motion from the center to tension and back.

Now change the order:

C → G → F → C
I → V → IV → I

The chords are the same, but the direction is different. After G, the ear usually expects a return to C, but F appears instead. The tension does not resolve immediately; it moves somewhere else.

Function is not only “which chord is this?” It is also “what came before it?” and “what happened after it?”

Functional substitution

If two chords play a similar role, one can sometimes replace the other.

In C major, IV and ii can both prepare the dominant:

C → F  → G → C
I → IV → V → I
C → Dm → G → C
I → ii → V → I

The role is similar: motion from tonic toward dominant. The sound is different: F sounds more direct, while Dm sounds softer.

The same applies to the tonic area:

C  = I
Am = vi

Sometimes vi can replace the expected I, but the result changes. Instead of full closure, you get continuation.

Functional substitution does not mean that the chords are identical. It means that they can do similar work inside a progression.

How to hear function

Function is easier to hear in context than in isolated chords.

A single G chord just sounds like G. But after C and F, it starts to feel like a dominant:

C → F → G → C

Listen not only to the chord quality, but to the feeling it creates.

FeelingPossible function
you can stop heretonic
you want to continuesubdominant or predominant
you want resolutiondominant

A simple listening test:

C → F

After F, the phrase feels open.

C → F → G

After G, the pull back to C becomes stronger.

C → F → G → C

After the final C, the progression feels closed.

Functions in minor

Minor keys follow similar principles, but the system is more flexible.

In A natural minor, the basic chords are:

Am–Bdim–C–Dm–Em–F–G
i–ii°–III–iv–v–VI–VII

Tonic:

i = Am

Predominant area:

iv = Dm
ii° = Bdim

Soft dominant from natural minor:

v = Em

For a stronger return to the tonic, minor-key harmony often uses a major dominant:

E7 → Am
V7 → i

This comes from the raised seventh degree:

G♯ → A
7 → 1

This is explained in detail in Chords in a Minor Key.

Five-minute exercise

1. Play the basic route

In C major:

C → F → G → C
I → IV → V → I

Name the functions:

tonic → subdominant → dominant → tonic

2. Replace IV with ii

C → Dm → G → C
I → ii → V → I

Compare F and Dm before G.

Both chords prepare the dominant, but they sound different.

3. Compare V–I and V–vi

G → C
V → I
G → Am
V → vi

The first motion sounds more complete. The second leaves continuation.

4. Change the order

Play:

C → F → G → C

Then:

C → G → F → C

The chords are almost the same, but the direction is different.

5. Transpose the model

Move I–IV–V–I to G major:

G → C → D → G

The functions stay the same, even though the chord names change.

Common mistakes

Treating function as a fixed property of a chord. G is the dominant in C major, but the tonic in G major.

Identifying function only by chord name. You need the key and the context.

Confusing function with chord quality. A major chord is not always tonic. A minor chord is not always predominant.

Learning function groups as rigid lists. Function groups help you navigate, but the real role depends on the musical surroundings.

Listening to chords in isolation. Function is heard through motion: before the chord, on the chord, and after it.

Assuming substitutions sound the same. IV and ii can play a similar role, but they have different colors.

Looking for function without a tonic. First find the center. Without a center, function loses its meaning.

Short summary

Chord function is the role a chord plays inside a key.

The chord name tells you which notes the chord contains. Function shows what the chord does in a progression: creates stability, opens motion, builds tension, or returns to the center.

The basic model is:

tonic → subdominant → dominant → tonic

In C major:

C → F → G → C
I → IV → V → I

Once you hear functions, a progression stops being a list of chords. It becomes motion: from stability to tension and back.
