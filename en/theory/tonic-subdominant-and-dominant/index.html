Tonic, Subdominant, and Dominant

The simplest functional model describes harmony as motion from home, through departure and tension, back home again: T–S–D–T.

July 25, 2026
Reader level: Arranger

Tonal harmony is not just a sequence of chords. It is motion.

One chord sounds like stability. Another moves away from it. A third creates tension and demands a return.

In the basic functional model, these roles are called:

  • T — tonic
  • S — subdominant
  • D — dominant

The simplest route is:

T → S → D → T

In C major:

C → F → G → C
I → IV → V → I

This model helps you hear harmony not as a list of chords, but as motion: stability → departure → tension → return.

In short: what T, S, and D do

FunctionSymbolSimple feelingWhat it does
tonicT“home”creates the center and stability
subdominantS“leaving home”opens motion
dominantD“we need to return”creates tension before the tonic

The tonic gives a point of reference. The subdominant moves the music away from the center. The dominant increases the expectation of return. The return to tonic closes the motion.

home → departure → tension → return

T, S, and D are functions, not chord names

In C major, the simple model looks like this:

T = C
S = F
D = G

But in another key, the chords will be different.

In G major:

G → C → D → G
I → IV → V → I

The functions stay the same, but the chord names change:

FunctionC majorG major
TCG
SFC
DGD

So T–S–D–T is not a fixed set of chords. It is a pattern of motion.

Tonic: the point of stability

The tonic is the center of the key. In C major, the tonic is the chord C. Music can begin, pause, or end on the tonic. If you play C and stop, the phrase can feel stable. The tonic gives the feeling that “we are in place.”

The tonic area can be wider than just the I chord. In C major, iii and vi sit close to the tonic:

I   = C
iii = Em
vi  = Am

They are not fully equal to the tonic, but they can create a similar feeling of support.

For example:

C  = C–E–G
Am = A–C–E

C and Am share two notes. That is why vi can sound like a softer tonic substitute, but without the same full sense of closure.

Subdominant: moving away from the tonic

The subdominant moves the music away from the center. In C major, the subdominant is the IV chord: F.

The motion C → F (T → S) sounds like a move away from stability.

After F, the phrase usually does not feel complete. It opens up and asks for continuation.

The subdominant does not create tension as strongly as the dominant. It expands the space and prepares further motion.

Dominant: tension before return

The dominant has the strongest pull back to the tonic.

In C major, the dominant is the V chord: G.

The chord G contains the leading tone B:

G = G–B–D

The note B sits a semitone below C and pulls toward it:

B → C
7 → 1

That is why the motion G → C (D → T) sounds like a clear resolution.

If you add the seventh, you get G7:

G7 = G–B–D–F

It contains two strong tendencies:

B → C
F → E

That is why V7–I sounds more directed than a simple V–I.

Why D leads to T more strongly than S does

Both subdominant and dominant can return to the tonic, but they do it differently.

Compare:

F → C
S → T

and:

G → C
D → T

F–C sounds like a soft return. G–C sounds like a stronger resolution. G7–C sounds even more directed.

The main reason is the leading tone:

B → C

The dominant contains a note that sits a semitone below the tonic and pulls toward it. The subdominant does not contain that same strong leading-tone pull.

So S–T closes the motion softly, while D–T feels like a clearer resolution.

The basic T–S–D–T route

In C major:

T → S → D → T
C → F → G → C
StepChordFunctionFeeling
TCtoniccenter
SFsubdominantdeparture
DGdominanttension
TCtonicreturn

This pattern does not describe all music, but it explains why I–IV–V–I sounds complete.

It has a beginning, motion, tension, and closure.

T–S–T and T–D–T

To hear the difference between subdominant and dominant, compare two short motions.

T → S → T
C → F → C

and:

T → D → T
C → G → C

In the first case, the return is soft. In the second, it is more directed.

S moves away from the center, but it does not demand resolution as strongly. D asks for the tonic more clearly.

Subdominant and predominant

The word “subdominant” can mean the specific IV chord:

IV = F in C major

But in practice, there is a wider area: chords that move away from the tonic and prepare the dominant.

In C major, ii belongs close to this area:

ii = Dm

Compare:

C → F  → G → C
I → IV → V → I

and:

C → Dm → G → C
I → ii → V → I

F and Dm sound different, but both can stand before G and prepare the return to C.

That is why the term predominant is often used: it means the area before the dominant.

A short practical map:

S area = IV and ii

IV is a specific scale degree. Subdominant or predominant function is a role in motion.

The dominant area is wider than V

The dominant is not only the V chord.

In C major, the dominant area includes:

V    = G
V7   = G7
vii° = Bdim

Bdim contains these notes:

Bdim = B–D–F

They are the upper notes of G7 without the root:

G7   = G–B–D–F
Bdim =   B–D–F

So vii° can also lead to the tonic:

Bdim → C
vii° → I

In simple song-based harmony, V and V7 are more common. But vii° clearly shows that dominant function is not about the chord name alone. It is about tension tones and their resolution.

Functional groups in major

In major, the basic function map looks like this:

FunctionMain chordsWider group
TII, iii, vi
S / predominantIVii, IV
DVV, vii°

In C major:

T group = C, Em, Am
S group = Dm, F
D group = G, Bdim

This map helps you analyze progressions and choose substitutions.

For example:

I → IV → V → I

can become:

I → ii → V → I

The functional route is similar:

T → S → D → T

but the color changes.

Functional substitution

Functional substitution means replacing a chord with another chord that has a similar role.

In C major, IV can be replaced by ii before the dominant:

C → F  → G → C
C → Dm → G → C

Both versions move from tonic toward dominant and back.

But the substitution does not make the chords identical. F sounds more direct. Dm sounds softer.

In the same way, vi can sometimes replace the tonic:

C → F → G → C
I → IV → V → I
C → F → G → Am
I → IV → V → vi

In the second case, instead of full closure, the progression continues. The chord vi sits close to the tonic area, but the feeling is different.

T–S–D in minor

In minor, the model stays useful, but it works more flexibly. In A minor, the tonic T is Am (i). The subdominant area S is Dm (iv). In natural minor, the dominant d is minor: Em (v).

This motion sounds soft:

Am → Dm → Em → Am
T  → S  → d  → T

But minor-key harmony often raises the seventh degree to create a major dominant:

G♯ → A
7  → 1

Then E or E7 appears:

E → Am
D → T

Compare the two versions:

Am → Dm → Em → Am
T  → S  → d  → T
Am → Dm → E → Am
T  → S  → D → T

The first version is softer. The second pulls more strongly back to the tonic.

This is explained in detail in Chords in a Minor Key.

T–S–D is a model, not a law

The T–S–D–T model is useful, but it does not have to describe every kind of music.

Music can:

  • stay in the tonic area for a long time;
  • avoid a strong dominant;
  • use loops without clear closure;
  • move through borrowed chords;
  • follow modal logic;
  • shift the tonal center.

For example, this progression:

Am–F–C–G

can sound cyclic and avoid a strong cadence.

That is not a mistake. The harmony simply does not aim for the classical T–S–D–T route.

The functional model is not there to declare everything else wrong. It helps you hear where there is a center, departure, tension, and return.

How to hear T, S, and D

Functions are best trained in context.

A single G chord is just G. But in C major, after C and F, it sounds like a dominant:

C → F → G → C

Listen not only to the chord, but to the feeling after it.

FeelingPossible function
you can stopT
you want to continueS or predominant
you want resolutionD
the motion feels closedreturn to T

A simple test:

C → F

After F, the phrase feels open.

C → F → G

After G, the pull toward C becomes stronger.

C → F → G → C

After the final C, the motion closes.

S → T

In both cases, the motion leads to the dominant, but the color changes.

4. Move the model to G major

T → S → D → T

The chord names change. The functions stay the same.

and:

Am → Dm → E → Am
T  → S  → D → T

Listen for the difference between the soft minor dominant and the stronger major dominant.

Common mistakes

Confusing function and scale degree. T, S, and D are functions. I, IV, and V are degrees in a specific key.

Thinking that subdominant means only IV. IV is the main subdominant chord, but ii often plays a predominant role too.

Thinking that dominant means only V. The dominant area also includes V7 and vii°.

Treating T–S–D–T as a universal law. It is a model of tonal harmony, not a required rule for all music.

Ignoring the minor dominant. In natural minor, v–i sounds softer, but it is still a valid sound.

Missing the difference between substitutions. IV and ii can play a similar function, but they have different colors.

Ignoring bass and inversions. The same chord can sound more stable or more tense depending on the bass and voicing.

Short summary

Tonic, subdominant, and dominant are the three basic functions of tonal harmony.

T = stability
S = departure from stability
D = tension before return

The main model is:

T → S → D → T

In C major:

C → F → G → C
I → IV → V → I

The tonic creates the center. The subdominant opens motion. The dominant creates expectation. The return to tonic closes the motion.

Once you hear T, S, and D, harmony stops being a set of chords and becomes movement.
