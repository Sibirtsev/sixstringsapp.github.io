What Is a Chord Inversion?

A chord inversion appears when the bass note is not the root, but another note from the same chord. The notes stay the same, but the harmonic feeling changes.

June 16, 2026
Reader level: Arranger

The same chord can sound stable, soft, tense, or directional. Sometimes the reason is not a new note, but the note that sits in the bass.

Take C major:

C–E–G

If C is the lowest note, we hear a regular C chord. If E is the lowest note, the chord still contains C, E, and G, but the feeling changes. The bass starts to lead the harmony differently.

That is how a chord inversion appears.

Simple definition

A chord inversion is a position of a chord where the bass note is not the root, but another note from the same chord.

For example, the C major chord contains three notes:

C–E–G

If C is in the bass, the chord is in root position:

C = C–E–G

If E is in the bass, this is the first inversion:

C/E = E–G–C

If G is in the bass, this is the second inversion:

C/G = G–C–E

The notes of the chord have not changed. Only the lowest note has changed.

Why the bass matters

The bass is the foundation of the harmony. Even if the upper notes stay the same, a different bass note changes the feeling of the chord.

Compare:

C   = C in the bass
C/E = E in the bass
C/G = G in the bass

In all three cases, the notes C, E, and G are present. But the ear hears them differently:

  • C sounds stable;
  • C/E sounds lighter and often leads forward;
  • C/G sounds less stable and may feel like preparation, suspension, or a passing chord.

An inversion does not change the chord itself. It changes its position and its role in a specific musical context.

Root position, first inversion, and second inversion

A triad has three possible positions.

PositionBass noteExample from CNotes from bottom to top
Root positionrootCC–E–G
First inversionthirdC/EE–G–C
Second inversionfifthC/GG–C–E

The main rule:

the position of a chord is defined by the lowest sounding note

Not by the order of notes in the chord symbol. Not by the easiest fingering. Not by which note is on top. The bass decides.

For example, C/E can be played like this:

E–G–C

Or like this:

E–C–G

In both cases, it is the first inversion of C major, because the lowest note is E.

First inversion: C/E

The first inversion appears when the third of the chord is in the bass.

In C major, the third is E:

C–E–G

If E is in the bass, we get C/E:

C/E = E–G–C

C/E sounds softer and lighter than C in root position. This inversion is often used to make the bass line smoother.

For example:

C → C/E → F

The bass moves like this:

C → E → F

Here C/E is not used to make the harmony “more complex”. It is used for motion. It helps lead the bass toward F.

Second inversion: C/G

The second inversion appears when the fifth of the chord is in the bass.

In C major, the fifth is G:

C–E–G

If G is in the bass, we get C/G:

C/G = G–C–E

C/G sounds less stable than C. The bass note is not the root, but the fifth, so the chord often feels like a transition, suspension, or preparation.

For example:

G → C/G → G

This can sound like an embellishment of the dominant: the bass stays on G while the upper voices move.

Inversions of seventh chords

A seventh chord has four notes, so it has more inversions.

Take C7:

C–E–G–B♭

Possible positions:

PositionBass noteSymbolNotes
Root positionrootC7C–E–G–B♭
First inversionthirdC7/EE–G–B♭–C
Second inversionfifthC7/GG–B♭–C–E
Third inversionseventhC7/B♭B♭–C–E–G

The third inversion is possible because a seventh chord has a fourth note: the seventh.

C7/B♭ sounds especially directional: the minor seventh is in the bass, and that note often wants to resolve downward.

Chord inversion and slash chord: what is the difference?

Slash notation shows which note should be in the bass.

For example:

C/E

This means:

C chord
E in the bass

If the bass note belongs to the chord, it is an inversion.

C major contains these notes:

C–E–G

E belongs to the chord, so C/E is an inversion.

But if we write:

C/D

D does not belong to C major:

C–E–G

So this is not an inversion. It is a slash chord with a different bass note.

In short:

C/E = inversion, because E belongs to C major
C/D = slash chord, because D does not belong to C major

In practice, both are written with a slash, so always check whether the bass note belongs to the chord.

Why inversions are useful

Inversions are not used to make harmony more complicated. They are used to control motion.

They help you:

  • make the bass line smoother;
  • connect chords without large jumps;
  • change the feeling of familiar harmony;
  • make a guitar or keyboard part less predictable;
  • create better voice leading;
  • keep the same chord while changing its direction.

For example, a simple progression:

C → F

Sounds clear, but the bass jumps from C to F.

If we add an inversion:

C → C/E → F

The bass moves more smoothly:

C → E → F

Even simple harmony starts to sound more connected.

Common examples of inversions and slash chords

C → C/E → F

A classic move with an ascending bass line:

C → C/E → F

Bass:

C → E → F

This movement often appears in pop music, rock, song accompaniment, and ballads.

G → G/B → C

Another common move:

G → G/B → C

Bass:

G → B → C

G/B leads smoothly into C. Instead of a direct move, the bass makes a more melodic rise.

Am → Am/G → F

Here the bass moves downward:

Am → Am/G → F

Bass:

A → G → F

Am/G is not an inversion of Am, because G does not belong to the Am chord:

Am = A–C–E

It is a slash chord. It is useful for the same practical reason: it helps create a bass line.

This example matters because inversions and slash chords often appear side by side in songs. They serve a similar practical purpose: they guide the bass.

How to see an inversion on the fretboard

On guitar, an inversion is defined by the lowest sounding note.

If you play C major and the lowest note is E, it is C/E. If the lowest note is G, it is C/G.

C/E = E in the bass
C/G = G in the bass

It is important to look not at the first note on a diagram, but at the lowest sounding string.

Sometimes a guitarist does not play every note of the chord. That is fine. What matters is that the bass note and the important intervals create the intended feeling.

For C/E, you need to hear E at the bottom. For C/G, you need to hear G at the bottom.

5-minute exercise

  1. Play C in root position.
  2. Play C/E.
  3. Play C/G.
  4. After each version, pause and listen to the bass.
  5. Play C → F.
  6. Then play C → C/E → F.
  7. Compare where the motion sounds smoother.
C       = C in the bass
C/E     = E in the bass
C/G     = G in the bass
C/E → F = smooth motion E → F

The main goal is to hear that an inversion changes not the chord name, but the direction of the harmony.

Bass line exercise

Build three short progressions:

C → C/E → F
G → G/B → C
Am → Am/G → F

Play each one slowly and sing the bass separately:

C → E → F
G → B → C
A → G → F

If the bass line sounds like an independent melody, the inversions are working musically.

Guitar exercise

  1. Find a simple C major shape.
  2. Find a C/E shape where the lowest note is E.
  3. Find a C/G shape where the lowest note is G.
  4. Play them with a metronome: C → C/E → C/G → C.
  5. Do not speed up.
  6. Make sure the bass note is clear.
  7. Then play C → C/E → F.

On guitar, it is useful to search for the bass note first, not the full shape. The bass note defines the inversion.

Common mistakes

Thinking that an inversion changes the chord itself. C, C/E, and C/G contain the same main notes: C, E, and G. The bass and the harmonic feeling change.

Ignoring the bass. In inversions, the bass is the main point. If the lowest note is not clear, the inversion loses its meaning.

Confusing inversions and slash chords. If the bass note belongs to the chord, it is an inversion. If it does not, it is a slash chord with another bass note.

Treating any guitar shape as an inversion. An inversion is defined not by comfortable fingering, but by the lowest sounding note.

Always playing the full chord. Sometimes the bass and a few important notes are enough. In an ensemble, other instruments may play part of the chord.

Using inversions without a purpose. Inversions are most useful when they make the bass line smoother or strengthen harmonic motion.

Short summary

A chord inversion appears when the bass note is not the root, but another note from the same chord. The set of notes stays the same, but the harmonic feeling changes. Inversions help make the bass smoother, connect chords, and control motion. The main thing is to listen to the lowest voice: it often explains why a familiar chord suddenly sounds different.
